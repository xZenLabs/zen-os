<!-- Documentation current through ZenOS v4.3.0. -->

All of KOReader's own menus, right inside Zen Settings, so you don't need to leave Zen Mode to change something.

- **In the Library**: File browser, Settings, Tools, Search, and Main menu.
- **While reading**: Navigation, Typesetting, Settings, Tools, Search, and Main menu.

Plugin entries show up here just like they do in KOReader.

Common spots:

- **Gestures**: Settings > Taps and gestures > Gesture manager
- **Book layout**: Typesetting > Document settings > Layout (reader only). Hold a preset to make it your default.

**Where:** Zen Settings > KOReader
