Optional tools and plugin integrations.

## Stats

Open the **Stats** tab from the Navbar for your reading dashboard. Widgets cover today, this week/month/year, all time, personal records, your library, the current book, reading trend, goals, and a reading calendar. Six slots total; the calendar takes two.

With **Edit mode** on, tap a widget to change its settings. You can also set the default text size, separators, and whether the week starts Sunday or Monday.

**Where:** Zen Settings > Extras > Stats

## Zen Keyboard and Zen Search

**Zen Keyboard** adds keyboard improvements. **Zen Search** improves search in the Library and reader, with optional whole-word matching (needs a restart).

**Where:** Zen Settings > Extras > Zen Keyboard / Zen Search

## ZenPM

Install the Zen plugin manager right from ZenOS. Once installed, the same item opens it. Supported on non-Android ARM devices.

**Where:** Zen Settings > Extras > Install ZenPM

## OPDS

![OPDS catalog](/images/zen_os/opds.webp)

![OPDS context menu](/images/zen_os/opds_context.webp)

Makes the OPDS catalog look like your Library: covers, mosaic or list view, rounded corners, and a hold menu for each item. Turn on **Prefer large covers** for sharper covers in mosaic.

**Where:** Zen Settings > Extras > Zen OPDS

## Rakuyomi

- **Return to chapter list on exit**: closing a manga chapter goes back to its chapter list. Turn off to go back to the Rakuyomi library.
- **Exclude from Home**: keeps manga chapters out of Home's recent books.

**Where:** Zen Settings > Extras > Rakuyomi

## Lockdown Mode

Restricts the Library, Controls, and reader. See [Lockdown Mode](/zen-os/docs/lockdown-mode).
