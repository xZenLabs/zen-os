<!-- Documentation current through ZenOS v4.3.0. -->

Version info and a few handy tools.

- **ZenOS version**, plus your **KOReader** version, **Device**, **Firmware**, and **IP address**. Include these when you report a bug.
- **Setup Guide**: rerun the first-launch walkthrough and the quick tours of Zen Settings and the page browser.
- **Report a Bug**: opens the bug report flow.
- **Quit KOReader**: exits after confirming.

**Where:** Zen Settings > About
