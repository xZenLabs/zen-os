ZenOS adds its own actions to KOReader. Put them on a gesture, a Controls button, a Navbar tab, a Launcher button, or anywhere else that lets you pick an action.

## Actions

| Action | What it does |
| --- | --- |
| ZenOS: Toggle Zen Mode | Zen Mode on/off. Stays on during Lockdown. |
| ZenOS: Toggle Lockdown Mode | Lockdown on/off. Also turns on Zen Mode. |
| ZenOS: Toggle Incognito Mode | Incognito on/off. |
| ZenOS: Home | Opens Home. |
| ZenOS: Library | Opens the Library. |
| ZenOS: Authors / Series / Tags | Opens that grouped view. |
| ZenOS: Open folder | Opens a folder you pick. |
| ZenOS: Sync progress (pull + push) | Syncs reading progress both ways. |
| ZenOS: Annotation viewer | Annotations for this book, or all books from the Library. |
| ZenOS: Table of contents | Opens the Zen TOC. *(reader)* |
| ZenOS: Annotations / Bookmarks / Highlights | Opens that page-browser tab. *(reader)* |
| ZenOS: Pinned pages | Opens your pins. *(reader)* |
| ZenOS: Toggle top / bottom reader status bar | Shows or hides one bar. *(reader)* |
| ZenOS: Toggle reader status bars | Both bars at once. *(reader)* |
| ZenOS: Toggle reader themes | Reader themes on/off. *(reader)* |

*(reader)* actions only work with a book open.

## Where to use them

- **Gestures**: Zen Settings > KOReader > Settings > Taps and gestures > Gesture manager
- **Controls**: Zen Settings > Interface > Controls > Buttons > **Add > Action**
- **Navbar**: Zen Settings > Interface > Navbar > Tabs > **Add > Action**
- **Launcher**: Zen Settings > Interface > Launcher > Buttons > **Add > Action**

Want a plugin screen that isn't an action? Use **Add > Plugin Menu** in the same places.
